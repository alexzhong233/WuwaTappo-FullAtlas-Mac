# WuwaTappo Full Community 1.2.2-alpha.1

基于官方国服 **1.0.3** 的 Mac 实验适配，面向 Apple Silicon / macOS 13 及以上。

- 保留本地全图鉴与桌面助手，适配新版前端、面板快照及切屏模块。
- 接入 F7 游戏模式、F8 切屏、F9 隐藏桌宠的快捷键配置接口。
- 自动测试、原生构建、签名与 ZIP / DMG 校验通过，角色和设置面板可显示。

**实验预发布，尚未完成完整业务验收。** 登录、输入监控授权后的计数和快捷键、多屏、助手任务及联机需继续验证。详见 `macos/docs/OFFICIAL_1.0.3.md`。

下载 ZIP 或 DMG 任一个即可。应用使用 Ad hoc 签名，未通过 Apple 公证。与 1.2.1 共用应用标识和数据目录，试用前请退出旧版并备份数据。不支持安装官方 Windows 或 FullAtlas Windows 更新包。
