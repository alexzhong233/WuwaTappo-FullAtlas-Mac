# 官方 1.0.3 实验适配记录

日期：2026-10-30。分支：`official-1.0.3`。整合版版本：`1.2.2-alpha.1`。`main` 仍保留基于官方 1.0.2 的 1.2.1 预览版。

## 资源与契约

- 官方国服安装包大小：201,697,504 bytes。
- SHA-256：`29b6f4aaeb0ad4db5a8002e3686435692fa0ddb88ea9389e89b53fb93932136e`，下载地址固定在 `upstream-cn.json`。
- 新版前端合并了 Tauri invoke 包装函数，更新了面板、登录、切屏模块和压缩变量名；新增 3 个快捷键命令和 3 个事件，移除 3 个原生对话框命令。已重新生成契约清单并核对既有计数和业务接口。
- FullAtlas 版本门禁明确允许这份已核验的 1.0.3 安装包；其他未知版本或摘要仍拒绝构建。

## 适配内容

- 更新会话屏障、更新提示、面板快照和关闭生命周期补丁，适应 1.0.3 前端结构。
- 助手左右宝箱计时从官方 readiness 表达式解析，避免压缩变量改名后误绑；校验准备后模块的导入与导出，覆盖新版切屏依赖。
- 实现快捷键配置、保存与录入状态接口，默认 F7 游戏模式、F8 切屏、F9 隐藏桌宠。沿用已有只监听输入流，不注入系统输入，也不新增计数流；录入时暂停快捷键触发。
- 原有本地图鉴、助手及账号写入限制保留，集成了 899 条图鉴映射。

## 待实机验收与限制

- 本机输入监控尚未授权，应用显示暂停提示；需用户授权后验证物理键鼠计数、快捷键触发和录入。
- 快捷键保存、重启恢复、全屏游戏模式、多屏切换和显示器记忆尚未完成端到端验收。原生菜单尚未增加独立的游戏模式菜单项。
- 本次未操作真实账号登录、奖励、兑换、联机或自动任务；需验收会话隔离、图鉴切换、助手面板及任务、图鉴关闭后的普通联机与 SDK 行为。
- 图片仍需官方 CDN；图鉴刷新和程序版本更新互相独立。
- 1.2.1 与此实验版共用应用标识和数据目录，请退出旧副本并备份数据后试用。

适合作为实验预发布候选，尚不能宣称 1.0.3 全部业务稳定。安装包、官方解包文件、运行日志及用户数据均不纳入源码仓库。
