# WuwaTappo Full Community 1.2.5

修 1.2.4 装完之后界面只剩一行「离线资源未就绪」，游戏画面完全不显示的问题。

## 出了什么问题

1.2.4 为了压体积，把离线素材缓存（`cache\`，约 100 MB）从安装包里拿掉了，改由运行期按需回源官方 CDN。但代码里「没有缓存」被当成了致命错误：

- 本地素材服务 `/status` 返回 `ready: false`；
- 前端把 `ready` 当启动闸门，直接 `throw`，把整个 `#app` 替换成一行「请通过本地版启动器运行」；
- 于是装完双击只能看到这行字，进不了游戏。

更糟的是同步函数本身要求目录里已有旧的 `atlas.json` / `asset_manifest.json` 才肯往下走，全新安装从零开始必然抛错——也就是说没有任何自愈路径，用户自己点「检查并同步」也救不回来。

## 现在的行为

- **装完直接进游戏**。缓存缺失不再阻塞启动，先按联机模式正常跑；素材在后台自动下载，不弹窗、不挡操作。
- **首次启动自动补齐素材**。设置页「本地全图鉴」会显示「正在下载本地素材 x/y」，下载完成后开关自动可用；失败会显示原因，可点「检查并同步」重试。
- **同步支持从零首拉**。不再依赖旧缓存文件；上次被强杀留下的半套 `cache_staging_*` 会在下次同步前清掉，历史代缓存只保留最近两代，不会越滚越大。
- **开关不再误导**。素材没就绪时开关是禁用的，并给出进度或失败原因，而不是弹一句「请使用本地版启动器」。
- **本地模式开着但缓存被清掉的机器不再打不开**。以前服务启动时直接 `raise` 退出，前端连状态都拿不到；现在退回联机模式并把状态落盘，补齐素材后重新打开开关即可。
- **真启动失败时提示可执行**。素材服务真的没起来（比如被杀软拦了），提示改成「用桌面快捷方式重新打开，仍不行看 host.stderr.log」。

## 实测

干净目录（无 `cache\`）启动本地素材服务：45 秒拉完 3098 张素材 / 106 MB，`/status` 变为 `ready: true`；随后开启本地模式、读取离线图鉴与素材均正常。缓存被删但记录了「本地模式开启」的场景，服务保持运行并自动退回联机模式。

## 安装

- **Windows**：Windows 10/11 x64，下载对应区服的 `.exe` 覆盖安装即可，原有的素材缓存和登录状态会保留。
- **macOS**：Apple Silicon / macOS 13 及以上，下载对应区服的 `.dmg`。

## 和 1.2.4 的关系

1.2.4 的 Windows 安装包有这个缺陷（macOS 侧不受影响），已经装了的请直接用 1.2.5 覆盖安装。1.2.4 里修好的黑框、图标、UAC、发版流程都包含在 1.2.5 内。
