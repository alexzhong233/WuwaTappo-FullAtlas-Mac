# WuwaTappo Full Community 1.2.4

修 1.2.3 发出去之后发现的问题：Windows 装完打不开、双击弹黑框、图标不对，以及打 tag 不会自动发版。

## Windows 安装包

- **不再弹控制台黑框**。之前的安装包拿 `start.cmd` 当入口（因为构建链里从来没有编译无控制台启动器），双击会先闪一个 cmd 窗口，快捷方式图标也是 cmd 的。现在 `build.ps1` 会先编译 `WuwaTappoLauncher.exe`，打包脚本缺了它就直接报错，不再静默回退。
- **图标对了**。桌面、开始菜单、卸载项统一用从官方客户端 exe 里提取的图标（`app.ico`），安装包本身也是这个图标。
- **安装界面重做**。换成 MUI2 流程：欢迎页 → 选目录 → 进度 → 完成页（可直接勾选启动），语言跟系统走（简中 / 英文）。覆盖安装会先安静结束正在运行的进程，不会再出现「装到一半文件被占用」。
- **卸载可以选择保留数据**。素材缓存和登录状态动辄上百 MB，卸载时会问一句，选「否」就留着，重装后接着用。
- **只弹一次 UAC**。启动器自身不再申请管理员权限，改用 `ShellExecuteW("runas")` 拉主程序，由系统按主程序的清单提权——不会再出现「启动器一次、主程序又一次」。
- **不再要求安装目录里自带 Chromium 内核**。1.2.3 的安装包把浏览器路径钉死在 `<安装目录>\runtime`，而发行包根本不带这个目录，于是双击直接报「找不到 WebView2」退出。现在入口 stub 会先检查该目录是否存在，不存在就不指定路径，交给 WebView2 自己去找机器上的系统运行时（Win11 自带；Win10 多半也随 Edge 装过）。安装器同时把这个检查提前到安装阶段，缺了会给出官方下载入口，而不是等你双击才炸。

## 发版流程

- **打 tag 就是发版**。之前 `publish` 固定带 `--draft`，推完 tag 只产出一个草稿，Releases 列表里看不到，很容易被当成「没发版」。现在四件产物齐全就直接发布；`-alpha` / `-beta` / `-rc` 自动标 Pre-release 不抢 Latest，正式号自动成为 Latest。
- **发版可以重跑自愈**。同 tag 的 Release 已存在时，重跑会补齐文件、同步标题和说明、并把草稿转正，网页上建错了也能修回来。

## 构建

- **国际服构建不再拉错缓存**。缓存准备脚本在工作目录没有 `local_config.json` 时一律走国服源，在别的机器上构建国际服会把国服素材混进去。现在按 `local_config > WUWA_REGION > 国服` 分派，与 `region.ps1` 一致。
- **换缓存目录抗干扰**。杀软或索引服务短暂占用目录会让改名抛 `WinError 5`，改成 5 次递增退避重试。
- **发行包统一不带离线图鉴**。`cache\` 不再进安装包，本机同步过素材也不会让包体积翻倍；图鉴按需回源官方 CDN。

## 安装

- **macOS**：Apple Silicon / macOS 13 及以上，下载对应区服的 `.dmg`，拖入「应用程序」。应用使用 Ad hoc 签名，未通过 Apple 公证，首次打开如被拦截请在「系统设置 → 隐私与安全性」里放行。
- **Windows**：Windows 10/11 x64，下载对应区服的 `.exe` 运行安装。装完用桌面快捷方式启动。主程序沿用官方客户端的清单，需要管理员权限，双击时系统会提示一次。

## 和 1.2.3 的关系

1.2.3 的 Windows 安装包带上面那些缺陷，已经下载过的请改用 1.2.4。macOS 侧功能一致，不必重下。
